# SWYNEX Task 4: Final Data Analytics Project

## Project Overview

This project combines data cleaning, exploratory data analysis,
and interactive dashboard development into a complete retail
sales analytics case study.

## Problem Statement

Retail transaction data can contain missing values, duplicate
records, inconsistent formats, and other data-quality issues.
The objective is to prepare the data, analyze sales performance,
and present useful business insights through a dashboard.

## Project Objectives

- Clean and prepare retail transaction data.
- Analyze sales performance and customer purchasing patterns.
- Identify monthly trends and country-wise differences.
- Identify top-performing products.
- Present key findings through an interactive Tableau dashboard.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Microsoft Excel
- Tableau Public
- Git and GitHub

## Project Structure

- data/: cleaned dataset
- scripts/: Python analysis scripts
- results/: generated analysis results
- dashboard/: final Tableau workbook

## Workflow

1. Clean and prepare the raw dataset.
2. Perform exploratory data analysis.
3. Calculate important business KPIs.
4. Build an interactive Tableau dashboard.
5. Document findings and recommendations.

## Key Business Insights

The final insights will be documented here after
calculating the results from the cleaned dataset.

## Conclusion

This project demonstrates an end-to-end data analytics
workflow, from data preparation to visualization and
business recommendations.
